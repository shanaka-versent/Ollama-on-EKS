Usage Guide

Use your API key with any OpenAI-compatible client:

# curl
curl https://${cloudfront_domain}/v1/chat/completions \
  -H "x-api-key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3.5","messages":[{"role":"user","content":"Hello"}]}'

# Python (OpenAI SDK)
from openai import OpenAI
client = OpenAI(
    api_key="YOUR_KEY",
    base_url="https://${cloudfront_domain}/v1",
    default_headers={"x-api-key": "YOUR_KEY"}
)
response = client.chat.completions.create(
    model="qwen3.5",
    messages=[{"role": "user", "content": "Hello"}]
)

# Claude Code / Continue.dev
export OPENAI_API_KEY=YOUR_KEY
export OPENAI_BASE_URL=https://${cloudfront_domain}/v1
